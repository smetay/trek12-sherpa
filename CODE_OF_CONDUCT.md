# Code of Conduct

This is a small hobby project about a board game. Let's keep it that way:

- Be kind and constructive. Assume good faith; disagree on ideas, not on people.
- No harassment, discrimination, personal attacks or unwelcome sexual attention, in any project space.
- Respect that maintainers volunteer their time — a "no" or a slow answer is not an offence.

If someone's behaviour makes you uncomfortable, contact the maintainer privately via the e-mail on the
GitHub profile [@smetay](https://github.com/smetay). Reports are handled confidentially. Maintainers may
edit, remove or reject contributions and comments that do not respect this document, and may ban repeat
offenders.

Inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
